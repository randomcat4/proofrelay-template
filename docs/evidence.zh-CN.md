# 证据与计算收据

[English](evidence.md)

证据分为一般论证、带完备覆盖证明的有限证书、只能找反例的证伪探针、保护实现的回归检查，以及只认证已编码陈述的形式化工件。它们不能互相冒充。

使用 `templates/attempt/receipt.json`，至少记录完整源码 commit、工作区是否干净、精确命令、去身份化环境、工具版本、UTC 起止时间、退出码、必要资源峰值、输入输出 SHA-256、理论搜索总数、实际执行数、剪枝理由、随机种子或非确定性说明，以及形式化工具链、构建命令、覆盖范围和公理报告。

远端执行前先提交代码和参数。远端只拉取固定 SHA 到隔离目录并运行已提交命令，只返回去敏证据；不得提交主机、端口、用户名、密钥、代理、云凭据或 `known_hosts`。

承重源码和紧凑输出保存在 Git。大型输出只有在存储持久、权限明确且仓库记录哈希与再生成方法时才可外置。不得只给修改后的“干净副本”算哈希并丢弃原件。
