# 治理与权限

[English](governance.md)

维护者负责冻结目标、分配路线、主审候选、判断证据门、更新接受状态、保护秘密以及合并或关闭 PR，但不能用这些权限删除负面证据或豁免未披露冲突。

贡献者只能修改工作单元分配的文件和路线，可以建议状态变化，但不能自行宣布接受、合并自己的主张或降低验证要求。

协议例外、目标变化、验证策略变化和接受决定应在 `docs/decisions/` 留下简短决策记录，写明背景、决定、证据、异议和后果。

审查冲突时保留双方报告，在解决前把主张标为 `INCONCLUSIVE`。权限缺失、上下文污染、不可核验收据或授权不足是流程阻塞，不是数学裁决。

自动化可以监控、校验、搭脚手架和通知，但不能静默重复投递、批准主张、合并状态变化或补猜缺失证据。状态没有变化时应保持安静。
