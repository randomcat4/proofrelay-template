# 独立验证

[English](verification.md)

维护者建立验证包时，只放冻结目标与版本、完整候选 commit SHA、判断主张所需的候选文件、已接受前提与公开引用、对抗清单和允许裁决词。除非隔离等级明确允许，不得放入作者讨论、主审结论、兄弟尝试、期望答案或未公开提示。

验证者必须重建目标并检查语义忠实性，先找承重步骤，再检查边界、方向、隐藏前提和范围；核对外部定理全部假设；从固定 commit 复现关键计算，并在可行时使用结构不同的实现；审计有限覆盖和剪枝；最终只按精确范围给 `CORRECT`、`INCORRECT` 或 `INCONCLUSIVE`。

验证者不能在同一工件里修补并认证候选。修复建议不具认证效力，修订候选必须回到作者路线。

若验证者看过兄弟路线、主审期望结论或早期版本，必须披露。未满足配置的独立性时，即使数学看似正确，也不能计入接受门。验证数量按独立且合格的工作单元计，不按文件、评论、重复运行或复制文本计。
