# Evidence

[简体中文](README.zh-CN.md)

Store decisive, reproducible scripts and compact outputs here or inside the owning attempt. Every computational claim needs a receipt. Add preserved artifacts to `manifests/artifacts.json` with `python scripts/update_manifest.py`.

Large generated files should normally be reproducible from committed source. If external storage is necessary, record a stable locator, access policy, byte count, SHA-256, and regeneration instructions.
