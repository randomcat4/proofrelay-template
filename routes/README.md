# Route registry

[简体中文](README.zh-CN.md)

Register each route in `state/PROJECT_STATE.json` and give it a self-contained Issue. A route records its target, owner, directory, start evidence, budget, fastest falsification test, current status, and immutable evidence links.

Recommended IDs are short and stable: `R01`, `R02`, or domain-specific equivalents. Do not reuse a retired ID for a different target.
