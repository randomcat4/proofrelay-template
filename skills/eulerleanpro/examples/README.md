# 小型端到端示例：同一个成果的四种视角

此例用于看清 Skill 的产物，不是新数学结果，也不是完整可安装 Lean 工程。本次打包未运行 Lean，不能把下面代码的存在当成测试通过。

目标是实数上的基本不等式 `|2ab| ≤ a²+b²`。文件如下：

- `EulerLeanProExample.lean`：两个边界引理和主结论；供复制到一个已有、兼容 Mathlib 的测试项目。
- `result-page.md`：不懂 Lean 的数学读者也可理解的陈述与证明。
- `roadmap.md`：人类/Agent 的任务规划，不是实际 DAG。
- `review-request.md`：具体检查什么，不预填通过结论。

## 在用户的隔离测试项目中验证

选择已有 Mathlib 工程，保持其 `lean-toolchain` 和库版本。将示例文件复制到该工程的库源码目录，按实际 lakefile/库入口纳入构建。
先构建依赖，再检查示例目标；对三个声明实际运行 `#print axioms`，确认没有 `sorryAx` 等不获准依赖。
文件内没有嵌入独立工具链，也不自动下载环境。请勿直接在有他人改动的研究树中执行示例。

真实 DAG 需在这次实际构建后用该工程成熟工具提取。本包没有把通过肉眼读源码预想的边写成“已提取 DAG”。

## 这个例子怎样教会分工

陈述审查者核对“所有实数 a,b”和绝对值结论；两个证明者可以分别研究上、下界，但这个小例无需实际开多 agent；集成者组合；叙述者解释两个平方；独立审查者查代码、说明和真实构建。
若上界依赖未证 helper，主结果即使自身没有 `sorry` 也仍未完成。这个负例在 `tests/fixtures/`。
