# 平方和界：形式化路线图

这是一项工作计划，不是真实 Lean 证明依赖 DAG。

主目标是对任意实数 a,b 证明 |2ab| ≤ a²+b²。
先核对实数表示与绝对值目标，再分别由 (a-b)² 和 (a+b)² 的非负性得到上界、下界，最后通过绝对值的双边界性质组合。

| 工作包 | 输入 | 交付 |
|---|---|---|
| 陈述 | 基础数学命题 | 准确 Lean 类型与语义核对 |
| 上界 | 平方非负 | `twice_mul_upper` |
| 下界 | 平方非负 | `twice_mul_lower` |
| 组合与说明 | 两个界 | 主结论和可读证明 |
| 独立检查 | 集成代码和说明 | 实际构建/语义/阅读结果 |

这个例子非常小，不需要创建五个真实 Issue；实际重大结果才按可认领工作包分配。
