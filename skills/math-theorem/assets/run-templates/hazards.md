# 命题风险表

列过的风险不是穷尽清单。验证者先检查通用核心，再从冻结命题派生领域风险。

## 通用核心

- 量词、否定和存在/全称是否保持：{{QUANTIFIERS}}
- 定义域、退化对象和边界：{{DOMAINS_AND_DEGENERACIES}}
- 选择、唯一性和可定义性：{{CHOICE_AND_DEFINABILITY}}
- 约化是否双向或足以推出目标：{{REDUCTION_REVERSIBILITY}}
- 外部定理的全部假设：{{EXTERNAL_THEOREM_ASSUMPTIONS}}
- 有限实验是否被错误提升为一般结论：{{FINITE_TO_GENERAL}}
- 未证引理是否等价于原命题或更强：{{CIRCULARITY}}

## 领域特异风险

- 代数：特征、交换性、单位元、挠元、商结构：{{ALGEBRA}}
- 图论/组合：环与重边、连通性、重数、方向、局部到全局粘合：{{COMBINATORICS}}
- 分析/优化：紧致性、极限交换、端点、正则性、常数依赖：{{ANALYSIS}}
- 概率：可测性、可积性、独立性、停时、零测集、耦合：{{PROBABILITY}}
- 算法/信息：允许访问的信息、随机种子、复杂度和适应性：{{ALGORITHMIC}}
- 当前命题新增风险：{{THEOREM_DERIVED_HAZARDS}}
